# CAD guidance

Public AutoCAD macOS, ezdxf and intent-loop Skills. Skill-only; no sandbox execution profile. FreeCAD execution lives in the separate freecad Pack. See PROVENANCE.md.

The CAD guidance pack is composed into the installed CAD product. Its DXF Skill now routes to the managed `cad.dxf.*` tools implemented by the single FreeCAD/CAD runtime; AutoCAD remains optional for DWG and live desktop work. See the FreeCAD manifest for immutable runtime assets.
